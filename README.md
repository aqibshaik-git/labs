# labs

Small concept labs that aren't part of a portfolio project: each one isolates a single idea (a memory-model race, a HashMap, a rate limiter) so you can see it work and break.

- `java/`: Java 25, Gradle, JUnit 5. `./gradlew test`
- `python/`: Python 3.14, uv, pytest. `uv run pytest`

Each lab folder links back to its lesson in `~/dev/learning`.
